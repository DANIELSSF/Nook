# Contribuir a Nook

Gracias por ayudar a mejorar esta pequeña isla para macOS.

## Reportar un problema

Incluye versión de macOS, arquitectura del Mac, versión de Nook, tipo de sesión (Terminal conectada o tmux propio), pasos para reproducir y resultado esperado. Si afecta a Claude Code o Codex, indica también la versión del CLI.

Antes de adjuntar capturas o diagnósticos, revisa que no contengan mensajes privados, rutas sensibles, credenciales o código de otros proyectos. Un ejemplo pequeño con datos ficticios suele ser suficiente.

## Proponer un cambio

- Explica el problema concreto y el comportamiento que propones.
- Mantén la isla compacta y la interacción de macOS consistente.
- Conserva la identidad de la pestaña original; cerrar una vista de Nook debe conservar sus procesos.
- Respeta Reducir movimiento y las preferencias de la mascota.
- Acompaña los cambios de comportamiento con pruebas que cubran el caso real.

Consulta [Desarrollo](docs/DEVELOPMENT.md) para compilar y ejecutar las pruebas. Las propuestas de interfaz deberían incluir una captura o una vista previa con datos sintéticos.

El proyecto todavía no tiene una licencia propia de redistribución elegida. Si quieres incorporar o reutilizar código, aclara ese alcance con el autor antes de hacerlo.
